API Reference

Integrate SentinelScan into your workflows with our REST API endpoints.

API root

Base URL: /api/v1

Format: JSON

Scan Endpoints

POST /api/v1/scans

Starts a new scan. Body: {"target": "example.com"}. Returns: {"scan_id": "uuid", "status": "PENDING"}

GET /api/v1/scans/<scan_id>

Polls scan status. Returns: {"scan_id", "status", "current_action", "progress_percent"}

GET /api/v1/scans

Lists scan history. Returns: {"scans": [{"scan_id", "target", "status", "date"}]}

GET /api/v1/reports/<scan_id>/json

Returns structured JSON report once complete (404 if not finished).

GET /api/v1/reports/<scan_id>/pdf

Downloads the PDF report (application/pdf).

Auth Endpoints

All endpoints require Authorization: Bearer <firebase_id_token> except /session which bootstraps it.

POST /api/v1/auth/session

Verifies the Firebase ID token in the Authorization header and creates the user's profile on first login. Returns the profile.

GET /api/v1/auth/me

Returns the logged-in user's profile.

PUT /api/v1/auth/theme

Updates theme preference. Body: {"theme": "light"|"dark"}

History Endpoints

Require same auth as scan endpoints.

GET /api/v1/history

The logged-in user's own scan history.

GET /api/v1/history/<scan_id>

A single historical scan record.

Standard Error Shape

Standard error format used by all endpoints.

{
  "error": "Not Found",
  "message": "The requested scan_id does not exist.",
  "code": 404
}
