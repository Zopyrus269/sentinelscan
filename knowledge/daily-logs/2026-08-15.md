# 2026-08-15

## Session 13 -- Google sign-in fixed (CSP was blocking the popup auth flow, not the icon)

User reported: logged-out fallback icon renders fine (session 12's fix held), but clicking it does nothing -- no sign-in popup, no error visible to the user. Two commits were needed to fully fix it; the first was necessary but insufficient.

**Fix 1 (`ad20337`)** -- `apps/backend/app.py`: CSP had no `frame-src` directive, so it fell back to `default-src 'self'`, which blocks the hidden `https://sentinelscan-3f82d.firebaseapp.com/__/auth/iframe` relay Firebase Auth's `signInWithPopup()` needs to communicate between the popup and the main page. Added `frame-src https://sentinelscan-3f82d.firebaseapp.com;`. Deployed to Render (~13 min build time), but clicking the icon still threw `FirebaseError: auth/internal-error` in the console -- fix 1 alone didn't resolve it.

**Fix 2 (`392e466`)** -- same file. Diagnosed by loading the live (still-broken) site with the user's one-time Chrome authorization and inspecting network requests after clicking the icon: `https://apis.google.com/js/api.js` (gapi's iframe/postMessage-relay loader, which the popup flow also depends on) was being blocked -- `script-src` only allowlisted `www.gstatic.com`, not `apis.google.com`. Added `https://apis.google.com` to `script-src`, and both `https://apis.google.com` and `https://accounts.google.com` to `frame-src` (covering whichever relay iframe gapi actually creates). Deployed to Render (~13 min build again).

**Verified live** (same one-time Chrome authorization, re-used within this session since it was for the same continuing task): clicked the Google icon on `https://sentinelscan-yd2u.onrender.com`, the profile button changed to the signed-in avatar, opened the dropdown and confirmed the account (Shreyas R, shreyasrangadi532@gmail.com) populated correctly, then signed back out to leave the site in its normal logged-out state before closing the tab.

**Both commits pushed directly to `main`** -- user explicitly authorized fixing this end-to-end including deploy verification in this session, so no separate approval was sought per-commit.

**Final CSP** (`apps/backend/app.py`, `add_security_headers`):
```
default-src 'self';
script-src 'self' 'unsafe-inline' 'unsafe-eval' https://cdn.tailwindcss.com https://www.gstatic.com https://apis.google.com;
style-src 'self' 'unsafe-inline' https://fonts.googleapis.com;
font-src 'self' https://fonts.gstatic.com;
connect-src 'self' https://*.googleapis.com;
img-src 'self' data: https://*.googleusercontent.com;
frame-src https://sentinelscan-3f82d.firebaseapp.com https://apis.google.com https://accounts.google.com;
frame-ancestors 'none';
object-src 'none';
```
