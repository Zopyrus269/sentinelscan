## Decisions worth remembering

- **Don't assume a Gemini API key format.** Google issues valid keys in more than one prefix format; do not add validation that rejects a key based on prefix pattern-matching. If a key looks wrong, the only reliable check is a live API call, not string shape.
- **Restart the Flask dev server after any `.env` change.** `load_dotenv()` only runs at process startup; there's no hot-reload for env files (only `.py` changes trigger Werkzeug's debug reloader).
