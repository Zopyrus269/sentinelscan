## Decisions worth remembering

- **Don't assume a Gemini API key format.** Google issues valid keys in more than one prefix format; do not add validation that rejects a key based on prefix pattern-matching. If a key looks wrong, the only reliable check is a live API call, not string shape.
- **Restart the Flask dev server after any `.env` change.** `load_dotenv()` only runs at process startup; there's no hot-reload for env files (only `.py` changes trigger Werkzeug's debug reloader).
- **Always create Google Cloud OAuth clients for this project inside `sentinelscan-3f82d` specifically** — verify the project selector before creating credentials, since GCP will silently let you create one in an unrelated/auto-generated project and Firebase will reject the resulting tokens with `INVALID_IDP_RESPONSE`.
- **Always run the local dev server as `http://localhost:5000`** — Firebase's authorized-domains whitelist for this project only covers `localhost`; a different host/port breaks Google Sign-In popups (both the site's own login and the bootstrap system's OAuth exchange) unless that origin is deliberately added to Firebase first.
